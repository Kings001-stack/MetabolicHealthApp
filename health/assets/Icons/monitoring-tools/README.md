# Monitoring Tools Icons

Use for health tracking and vitals throughout the app (cards, headers, lists, buttons).

Suggested files:
- blood-sugar.json (#FF5722)
- glucometer.json (#FF5722 or Neutral #757575)
- glucose-level.json (#FF5722)
- blood-pressure.json (#E91E63)
- sphygmomanometer.json (#E91E63 or Neutral #757575)
- heart-rate.json (#E91E63; alert #E53935)
- weight-scale.json (#2196F3)
- bmi.json (#2196F3)
- pills.json (#9C27B0)
- medicine-reminder.json (#9C27B0; warning #FFB300)
- capsule-clock.json (#9C27B0; warning #FFB300)
- steps.json (#4CAF50)
- running.json (#4CAF50)
- activity-tracker.json (#4CAF50)

Guidelines:
- Prefer simple loop or minimal motion; these appear in lists/cards.
- Keep sizes optimized; avoid heavy particle effects.

Primary metrics:
- Blood Sugar: `#FF5722`
- Blood Pressure: `#E91E63`
- Weight: `#2196F3`
- Medication: `#9C27B0`
- Heart Rate (informational): `#E91E63`; (alert/critical): `#E53935`

Trends and states:
- Trend Up: `#4CAF50`
- Trend Down: `#E53935`
- Trend Stable: `#9E9E9E`
- Reminder (med): align with System Engagement Warning `#FFB300` or use medication accent `#9C27B0`

Dark mode adjustments:
- Blood Sugar: `#FF7043`
- Blood Pressure: `#EC407A`
- Weight: `#42A5F5`
- Medication: `#AB47BC`
- Trend Stable neutral: `#E0E0E0`

Notes:
- Keep backgrounds transparent; let cards/containers provide background.
- Prefer single-color or limited-color icons per metric for consistency.
