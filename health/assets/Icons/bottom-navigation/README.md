Suggested files:
- home.json (primary #4CAF50, inactive #999999)
- dashboard.json (optional) (primary #4CAF50, inactive #999999)

- menu.json (optional) (primary #4CAF50, inactive #999999)
- more-options.json (optional) (primary #4CAF50, inactive #999999)

Guidelines:
- Keep file sizes small; these render frequently.
- Prefer a subtle idle animation. Avoid heavy loops.

## Color Guidelines

- Active tab: `#4CAF50` (Brand Green)
- Inactive tab: `#999999` (Neutral Gray)
- Focus/press: Optional slight scale/play; keep color consistent with active

Dark mode adjustments:
- Active tab: `#66BB6A`
- Inactive tab: `#E0E0E0`

Notes:
- Keep backgrounds transparent; let the tab bar provide background color.
- Prefer single-color or limited-color icons for consistent theming.
