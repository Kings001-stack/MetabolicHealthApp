# Nutrition Icons

Use for food, meals, recipes, hydration, and nutrition-related UI.

Suggested files:
- water-drop.json (#00BCD4; alt #03A9F4)
- drink-water.json (optional) (#00BCD4; alt #03A9F4)
- hydration.json (#00BCD4; alt #03A9F4)
- food-calorie.json (#2196F3)
- nutrition-facts.json (#2196F3)
- carb-count.json (#2196F3)
- chef-hat.json (#FF9800; neutral #757575)
- cooking-recipe.json (#FF9800; neutral #757575)
- low-carb-food.json (#4CAF50)

Guidelines:
- Prefer subtle looping; these often appear in lists and tabs.
- Keep hydration icons distinct (droplet vs glass) if needed.

Primary accents:
- Hydration: `#00BCD4` (Cyan 600) or `#03A9F4` (Light Blue 500) – pick one for consistency
- Recipes / Chef Hat: `#FF9800` (Orange 500) or Neutral `#757575` if secondary
- Carb Counter / Nutrition Facts: `#2196F3` (Blue 500)
- Healthy Food (snacks/low-carb): `#4CAF50` (Green 500)

Dark mode adjustments:
- Hydration: `#26C6DA` or `#29B6F6`
- Recipes: `#FFB74D` (softer on dark)
- Neutral icons: `#E0E0E0`

Notes:
- Keep backgrounds transparent; let section cards style the background.
- Prefer single-color or limited-color sets to maintain consistency across lists.
